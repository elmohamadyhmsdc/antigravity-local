# 03 — الأشخاص والمراجعة

المبدأ: **شخص / شخصية أنمي / مجموعة** هم نفس النوع من الشاشات. الفرق `kind` فقط (ArcFace للبشر، CCIP للأنمي). كل أنواع المراجعة (غير مصنف، اقتراحات، تكرارات، مشابه) طوابير داخل **شاشة واحدة**.

---

## P1 — الأشخاص `/people`
**القالب:** T1 · **الغرض:** كل من تعرّف عليه التطبيق.

### AppBar
`الأشخاص (العدد)` · **بحث** (يتوسع inline) · ⚙

### المحتوى
1. `SegmentedBar`: **أشخاص ‖ شخصيات ‖ مجموعات**
2. `ReviewInboxBanner` — يظهر لو فيه عناصر للمراجعة: "١٢ وجه غير مصنف · ٥ اقتراحات · ٢ تكرارات" → `/review`
3. `FilterBar`: ترتيب (الاسم / الأكثر صوراً / الأحدث) + فلتر مجموعة (chips)
4. `EntityGrid` من `EntityCard(person|character|group)`.

> أُلغيت القائمة ⋮: "إدارة المجموعات" = قسم مجموعات، "مراجعة" = البانر، "أجسام" = تبويب استكشاف، "غير مصنف" = طابور، "تنظيم الملفات" = إجراء داخل الشخص/المجموعة، "فحص ملف" = Settings ▸ Library & Scan.

### الإجراءات
| الفعل | النتيجة |
|---|---|
| نقر | P2 (أو P3 في قسم المجموعات) |
| ضغط مطول | تحديد |
| FAB "+" | قسم أشخاص/شخصيات: `NameSheet` + اختيار وجه اختياري ← شخص جديد. قسم مجموعات: `NameSheet` ← مجموعة |

**تحديد متعدد:** دمج (يتطلب 2) · نقل لمجموعة · تنظيم الملفات · حذف.

### حالات
- empty (أول مرة): "شغّل الفحص عشان نتعرف على الوجوه" → زر يبدأ الفحص.
- لا نتائج للبحث.

## P2 — الشخص `/people/:id`
**القالب:** T3 · نفسه للبشر والشخصيات.

### `DetailHeader`
- `Avatar` كبير: نقر = `expand`، ضغط مطول = `FacePicker` (تغيير الصورة الرئيسية).
- الاسم + قلم ← `NameSheet`.
- شارات: النوع · المجموعة (نقر ← `GroupPicker`) · العدادات (صور/فيديو/وجوه).
- `QuickActions`: **Reface بهذه الهوية** · **درّب موديل** · **وسائطه** (يقفز لتبويب الوسائط).
- ⋮ (خاص بالشخص): إعادة تسمية · نقل لمجموعة · دمج مع... · تنظيم الملفات · تصدير بيانات التدريب · حذف.

### التبويبات (4)
| التبويب | المحتوى |
|---|---|
| **الوسائط** | `MediaGrid` مقيّدة بالشخص + فلتر (الكل/صور/فيديو). نقر ← L3 بسياق `source=person` |
| **الوجوه** | `CropGrid` مرتبة بالجودة/الزاوية. نقر على وجه ← `EntityActionSheet(Face)` (اجعله رئيسي · **صحّح الربط** ← `CorrectionSheet` · وجوه مشابهة · حذف). chip "المرفوضة لهذا الشخص" لعرضها والتراجع. أعلى التبويب: بطاقات "اقتراحات لهذا الشخص" (قبول/رفض) و"قد يكون نفس الشخص" (← Merge) |
| **الأجسام** | `SegmentedBar` فرعي: **وضعيات ‖ أطقم ‖ وشوم ‖ جماعية ‖ أنشطة** — كل واحد هو **نفس `CollectionView` اللي في Explore** (E2) بس `person=:id`. ممنوع تنفيذ مختلف |
| **الاستوديو** | `SegmentedBar`: **موديلات ‖ Datasets ‖ نتائج** — `EntityList` مقيّد بالشخص + CTA كبير "درّب موديل" |

## P3 — المجموعة `/groups/:id`
**القالب:** T3 · (كانت `IdentityGroupsScreen` + `_GroupMediaScreen`)

- Header: اسم (`NameSheet`) · عدد الأعضاء · ⋮ (إعادة تسمية · تنظيم الملفات · حذف المجموعة — الأعضاء يبقوا).
- تبويبان: **الأعضاء** (`EntityGrid`، "+" يضيف عبر `PersonPicker` متعدد، تحديد ← إزالة من المجموعة) ‖ **الوسائط** (`MediaGrid` لكل وسائط الأعضاء).

## P4 — مركز المراجعة `/review`
**القالب:** T2 · Query: `queue`, `kind`, `person`, `album`, `face`.
يحل محل: `ReviewScreen`, `QuickReviewScreen`, `AlbumReviewScreen`, `UnsortedScreen`, `SimilarFacesScreen`, `ReviewMediaViewer`.

### بدون `queue`: صفحة الطوابير
5 بطاقات `EntityCard(hero)` بالعدادات: **غير مصنفة** · **اقتراحات** · **تكرارات محتملة** · **ربط الأجسام** · **المستبعد**. + `SegmentedBar` نوع (أشخاص ‖ شخصيات).

### الطوابير
| `queue` | الشكل | الإجراءات |
|---|---|---|
| `unsorted` | `CropGrid` (فلتر جودة) | **تحديد** ثم `BulkActionBar`: تعيين لشخص (`PersonPicker`) · شخص جديد من المحدد · تجاهل |
| `suggestions` | `SwipeDeck`: بطاقة وجه مقترح + الشخص المقترح | يمين = تأكيد · يسار = رفض · أعلى = تخطي. **نفس الثلاثة كأزرار ظاهرة** (إتاحة). زر "قارن" يفتح درج بأفضل 3 وجوه مؤكدة. "فتح الصورة" ← L3 يبرز الوجه. يدعم `person=` و`album=` كنطاق |
| `duplicates` | `EntityList` أزواج (أ ‖ ب) + نسبة الشبه | نقر ← P5 Merge · "ليسوا نفس الشخص" يسجل `distinct_from` |
| `bodyLinks` | `EntityList` | قبول / رفض |
| `similar` (+`face=`) | `CropGrid` وجوه قريبة من وجه معين | نفس `BulkActionBar` بتاع `unsorted` |
| `excluded` | `SegmentedBar` (وجوه ‖ أجسام ‖ مناطق ‖ أدوات) + `CropGrid`/`EntityList` | كل التصحيحات السلبية: **ملوش صاحب** (العنصر لسه ظاهر في المعرض، بس بشارة "بدون مالك") · **مش حقيقي** (مخفي من العرض) · **ليس هذا الشخص** (مع اسم الشخص). تحديد ← **تراجع** (يرجّعه للتلقائي) · تعيين لشخص. هو المكان الوحيد لمراجعة/تراجع كل التصحيحات السلبية |

كل الطوابير: `UndoSnackbar` بعد كل قرار؛ شريط تقدم "٣٠ من ١٢٠".

## P5 — الدمج `/merge/:a/:b`
**القالب:** T4 (خطوة واحدة)
- `AdaptivePair`: بطاقتان (أ ‖ ب) فيهم الصورة والاسم والعدادات (صور/وجوه/موديلات/وشوم).
- اختيار الاسم الدائم (`SegmentedField`: اسم أ ‖ اسم ب ‖ مخصص ← `NameSheet`).
- `StatusNotice`: "الدمج ذري ويحفظ النتائج والمهام والـ datasets والوشوم".
- `StickyActionBar`: إلغاء ‖ **دمج** → يفتح P2 الموحد.

---

## P6 — تنظيم الملفات `/people/:id/files` (أو `/groups/:id/files`)
**القالب:** T4 (معاينة ← تنفيذ)
1. **معاينة:** جدول (المسار الحالي ← المسار المقترح `DCIM/Your Gallery/<Group>/<Person>/`). الصور المشتركة بين أكثر من شخص: `SegmentedField` اختيار مالك الملف.
2. **تنفيذ:** `ProgressCard` + سجل تراجع (Journal) يتحمل إغلاق التطبيق وسط النقل. النقل عبر MediaStore بدون إعادة ضغط.
3. **انتهاء:** ملخص + زر "تراجع عن النقل".
