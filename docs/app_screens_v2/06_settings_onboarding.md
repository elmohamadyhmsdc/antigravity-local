# 06 — البداية والإعدادات

المبدأ: **الـ PC اختياري.** التطبيق يتصفح ويفحص الصور محلياً بدونه؛ الـ PC لازم فقط للفحص بالذكاء الاصطناعي وللاستوديو. أي شاشة تحتاج PC تعرض `ReadinessBanner` بدل ما تمنع الدخول.

---

## O1 — Welcome `/welcome`
**T6** (بدون AppBar) · شعار + جملة واحدة عن الخصوصية والبيانات على الهاتف.
- زر أساسي واحد: **اربط الكمبيوتر** ← O2.
- زر ثانوي: **تصفح الصور بدون كمبيوتر** ← O3 (ثم `/library`).
- لو التطبيق اتفتح برابط `agmobile://pair?...` ← يروح O2 مباشرة بالبيانات مملوءة ويطلب تأكيد البصمة.

## O2 — الاقتران `/pair`
**T4** — شاشة واحدة بدل Welcome-QR وManual:
`SegmentedBar`: **مسح QR ‖ إدخال يدوي** (نفس `PairingController`).
- **QR:** كاميرا + إطار؛ بعد القراءة تعرض **ملخص تأكيد** (اسم الـ PC · البصمة المختصرة) ثم "اقتران".
- **يدوي:** عنوان IP · المنفذ (8443) · كود الاقتران · "اتصل وتحقق" (يعرض بصمة الشهادة للمقارنة مع شاشة الـ PC).
- نجاح ← O3. فشل ← `ErrorState` يشرح السبب (Wi-Fi مختلف / Firewall / كود خطأ).

## O3 — الأذونات `/permissions`
**T4** (خطوة واحدة): بطاقتان:
1. **الصور والفيديو** (مطلوبة): حالة (ممنوحة/جزئية/مرفوضة) + زر "منح".
2. **الإشعار والخلفية** (اختيارية): شرح الإشعار الدائم؛ "تخطي — أضبطها لاحقاً من الإعدادات".
→ "متابعة" ← `/library`.

---

## S1 — الإعدادات `/settings`
**T6** · AppBar: ← · "الإعدادات". `SettingGroup`s بترتيب ثابت:

| المجموعة | الصفوف (`SettingTile`) |
|---|---|
| **عام** | **النشاط** (`nav` + Badge عدد الجاري) ← `/activity` |
| **الكمبيوتر** | **الكمبيوتر** (`nav`: نقطة حالة + اسم الـ PC) ← S2 |
| **المكتبة** | **المكتبة والفحص** (`nav`) ← S3 |
| **الخصوصية** | **الخصوصية والقفل** (`nav`) ← S4 · **التخزين** (`nav`: الحجم) ← S5 · **النسخ الاحتياطي** (`nav`: آخر نسخة) ← S6 |
| **النظام** | **التشغيل في الخلفية** (`nav`: الحالة) ← S7 |
| **عن التطبيق** | الاسم · الإصدار · التراخيص |

---

## S2 — الكمبيوتر `/settings/computer`
(كانت `ConnectionScreen`)
1. **بطاقة الحالة:** أخضر جاهز / أصفر يتحقق / أحمر غير متصل · اسم PC · العنوان · "اختبار الاتصال".
2. **جاهزية الموديلات** (`ResourcePanel`): Reface · Restyle · LoRA (تدريب/توليد) · الأجسام والأدوات. القائمة والتسميات **كما يعرضها `resource_panel.dart` حالياً** (من قدرات الـ PC)، كل صف: جاهز/ناقص/غير مُختبر.
3. **العنوان:** "اقتران مرة أخرى" ← O2. (QR/يدوي داخل O2).
4. **فك الاقتران** (`SettingTile(danger)` ← `ConfirmSheet`).

## S3 — المكتبة والفحص `/settings/library`
(كانت `SourcesScreen` + `AnalyzeScreen` + `InsightsScreen` + أجزاء من Home)
1. **نظرة عامة:** إجمالي الوسائط (صور/فيديو/حجم) · وجوه (مصنفة/غير مصنفة) · أشخاص/شخصيات · أجسام ووضعيات · **أكثر الأشخاص ظهوراً** (مخطط بسيط).
2. **المصادر:** `SettingTile(switch)` لكل ألبوم (تضمين/استبعاد) + عدد الوسائط.
3. **أفعال الفحص:** **افحص الآن** (يبدأ ← يعرض `ActivityPill`) · **إعادة فحص شامل** (`ConfirmSheet`) · **حلّل ملف...** (يختار ملف + النوع: بشر/أنمي/أدوات ← يعرض النتائج).
4. صف: "الملفات التي تعذر فحصها (N)" ← `/activity` (القسم المناسب).

## S4 — الخصوصية والقفل `/settings/privacy`
- **قفل التطبيق** (switch) ← يتأكد بمصادقة النظام.
- `AppLockGate`: غلاف على كل التطبيق، بيقفل لما التطبيق يروح الخلفية ويطلب مصادقة النظام؛ نجاح ← يرجع لنفس الشاشة بدون إعادة تحميل.
- مهلة القفل وPIN وحماية لقطات الشاشة مش جزء من v2 (08 افتراض #9).

## S5 — التخزين `/settings/storage`
- مخطط توزيع: قاعدة البيانات المشفرة · القصاصات (وجوه/أجسام) · مصغرات · مؤقت.
- أفعال: **مسح مصغرات الكاش** · **تنظيف ملفات المعالجة المؤقتة** (كل واحد `ConfirmSheet` عادي يشرح إعادة بنائها).

## S6 — النسخ الاحتياطي `/settings/backup`
`SegmentedBar`: **إنشاء ‖ استعادة**
- **إنشاء:** كلمة المرور (`PasswordSheet` مع تأكيد وقوة) ← AES-GCM-256 + PBKDF2 ← تصدير/مشاركة ملف `.agbackup`/`.enc`.
- **استعادة:** اختيار ملف ← كلمة المرور ← فحص السلامة ← **`ConfirmSheet` خطير** ("سيستبدل البيانات الحالية") ← إعادة تشغيل التطبيق.
- أعلى الشاشة: آخر نسخة + تذكير لو مر > 14 يوم (بدل بانر Home).

## S7 — الخلفية وتوفير الطاقة `/settings/background`
- **خدمة الإشعار الدائم** (switch): تحمي الفحص والمهام عند قفل الشاشة.
- **تجاوز تحسين البطارية** (`action`): يفتح إعدادات النظام (الهدف: Unrestricted).
- حالة حالية (✓/✗) لكل شرط + شرح مختصر.
