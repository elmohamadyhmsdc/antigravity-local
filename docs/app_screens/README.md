# دليل وتوثيق شاشات تطبيق Your Gallery

مرحباً بك في الدليل الشامل والمفصل لجميع شاشات وواجهات تطبيق **Your Gallery** (تطبيق معرض الصور والذكاء الاصطناعي للهواتف الذكية).

يوثق هذا الدليل بنية التطبيق الكاملة (68+ سطحاً وواجهة تفاعلية)، محتويات كل شاشة بالتفصيل الدقيق، عناصر التحكم، القوائم، أزرار التفاعل (Actions)، الإيماءات (Gestures)، وحالات العرض المختلفة (الحالات الفارغة، التحميل، الأخطاء).

---

## 🗺️ خريطة التنقل الرئيسية (Navigation Architecture)

يعتمد التطبيق على بنية **Gallery-First** مدعومة بنظام توجيه `GoRouter` مع شريط تنقل سفلي دائم (`AppShell`) يحتوي على 4 وجهات رئيسية:

```
AppShell (شريط التنقل السفلي)
 ├── 1. المعرض (Gallery)       -> /library   (LibraryScreen)
 ├── 2. الأشخاص (People)       -> /people    (PeopleScreen)
 ├── 3. الاستكشاف (Discover)    -> /discover  (DiscoverScreen)
 └── 4. الاستوديو (Studio)      -> /studio    (StudioScreen)
```

بالإضافة إلى الشاشات التابعة والمستقلة عبر مسارات مخصصة وشيتات تفاعلية منبثقة (Modal Bottom Sheets).

## 🎨 المفاهيم المشتركة وأنماط التفاعل (Interaction Patterns)

1. **التعامل مع الوسائط المحلية أولاً (Zero-Copy Local Browsing):**
   - المعرض يتصفح مباشرة ملفات الهاتف عبر Android MediaStore دون الحاجة لفحصها مسبقاً على السيرفر.
   - الفيديوهات تشغل عبر رابط `content://` المباشر دون نسخ مئات الميجابايت إلى الذاكرة المؤقتة، مع إمكانية الفتح في مشغل سامسونج النيتيف.
2. **الخصوصية التامة والحفظ المحلي (On-Device Ownership):**
   - قاعدة البيانات محلية مشفرة بالكامل بـ SQLCipher ومفاتيحها في Android Keystore.
   - الفحوصات والذكاء الاصطناعي لا تحتفظ بأي بيانات شخصية على السيرفر بعد المعالجة، ويتم تنظيف كل الملفات المؤقتة تلقائياً.
3. **التسمية والتحكم الشامل (Universal Naming & In-Place Editing):**
   - يمكن للمستخدم تسمية وتعديل أسماء الأشخاص، الشخصيات، الوضعيات، الملابس، الأدوات، ومناطق الجسم الحساسة بأسماء مخصصة بحرية.
4. **التكبير والبحث البصري (Universal Image Expansion & Lens):**
   - في أي مكان تظهر فيه صورة مصغرة (Face Crop، Body Crop، Result، Media)، يمكن الضغط على زر التكبير لفتح الصورة بحجم كامل مع إمكانية التمرير، والتكبير بالإصبعين، والبحث المباشر عبر Google Lens.
