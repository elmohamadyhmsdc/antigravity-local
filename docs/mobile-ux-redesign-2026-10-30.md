# Your Gallery — إعادة تصميم تجربة الموبايل

التاريخ: 30 أكتوبر 2026. المرجع هو الكود الحالي في `mobile/lib`، وليس الخطط القديمة.

اعتمد المستخدم الاتجاه البصري وطلب تنفيذه ثم المتابعة. تم تطبيقه في مصدر Flutter كما هو موضح أدناه؛ أوامر Flutter والاختبارات والـbuild لهذه الدفعة لم تُشغّل، وفق اختيار المستخدم السابق.

هذه الوثيقة تغطي **32 شاشة فعلية**: 29 مسارًا معرفًا في `Routes`، مع شاشات تفاصيل الشخص والمهمة والنتيجة. مسارات `/datasets` و`/media` و`/merge` بادئات لشاشات ذات معرّفات وليست صفحات قائمة مستقلة.

## الهدف وقرارات التصميم

المستخدم يقدر يعمل ثلاث حاجات بسهولة: ينظم مكتبته، ينشئ تعديلًا، ويرجع يكمل شغله أو يشوف النتيجة. كل شاشة تقدم إجراء أساسيًا واضحًا، وتعرض التفاصيل المناسبة للمرحلة الحالية.

- الاحتفاظ بالتنقلات الخمسة الحالية: Home / People / Library / Studio / Jobs، حتى تظل أماكن الوظائف مألوفة.
- الرئيسية تقدم الإجراء التالي: بدء فحص، مراجعة قرارات معلقة، فتح الأداة أو النتائج. إعدادات الاتصال لا تزاحم المحتوى الأساسي.
- الصور والوجوه هي المحتوى الأساسي. خلفيات فاتحة مائلة للأخضر، أخضر هادئ للإجراء الأساسي، ودعم الوضع الداكن. الأحمر للخطأ أو الحذف.
- استعمال خط النظام الحالي؛ لا خطوط أو مكتبات جديدة. مسافات 8 / 12 / 16 / 20 / 24، أزرار أساسية بارتفاع أدنى 52، ونصوص تسند الوظيفة بدل المصطلحات التقنية في مداخل الأدوات.
- الشاشات الطويلة تسمح بتمرير المحتوى، مع زر تنفيذ ثابت في شاشات الإنشاء والفحص. إعدادات التدريب المتقدمة داخل قسم قابل للفتح.
- الرسائل تشرح سبب التوقف وتقدم إجراءً مناسبًا. حالات عدم وجود نتائج تقدم مسح الفلاتر أو بدء العمل.
- بيانات المكتبة والنتائج تظل على الموبايل. انقطاع الـPC لا يساوي فقد البيانات. الفحص وإنشاء وظائف جديدة يتبعان متطلبات الاتصال الموجودة.

## تفاصيل Reface

1. **Target:** اختيار Gallery أو Files، ثم الصورة أو الفيديو. الفيديو يعرض المدة والتشغيل ونطاق القص. يختار المستخدم كل الوجوه أو أشخاصًا محددين؛ في حالة التحديد يعرض الأشخاص المجمعين وصورهم، مع إعادة الفحص أو فحص الإطار الحالي عند عدم ظهور شخص.
2. **Source identity:** شخص من المكتبة أو صور/فيديوهات مباشرة. اختيار الهوية المقصودة عند وجود أكثر من شخص، واختيار الوجوه المرجعية. حفظ/تحميل هوية مسماة، واستخدام هوية LoRA عند توفرها. الهوية المدربة خيار مصدر إضافي عند توفر ملفاتها.
3. **Quality:** مسار Reface الموحد الحالي مع Fast / Balanced / More detail ووصف خيارات استعادة التفاصيل. تحديث توحيد المسار من العمل المتزامن محفوظ؛ لا تعيد هذه الواجهات محددات V2/V3 القديمة ولا تغير إعدادات المعالجة أو طلبات الـAPI.
4. **Review & create:** ملخص نوع الوسائط والهوية والأشخاص ونطاق الفيديو، معاينة قبل التنفيذ الكامل، ثم إنشاء المهمة. بعد الحفظ تنتقل الواجهة لتفاصيل المهمة الموجودة.

مؤشر `Step n of 4` واضح، محتوى الخطوة فقط هو الظاهر، وBack / Next ثابتان. الرجوع داخل الفورم لا يرسل مهمة أو يعيد اكتشاف الوجوه تلقائيًا. حفظ المسودة بعد إغلاق الشاشة غير مضاف.

## حالات مشتركة ومكونات غير مستقلة

| الحالة / المكون | السلوك المطلوب |
|---|---|
| App lock | توثيق الجهاز عند تفعيل القفل؛ إظهار شاشة فتح قبل المحتوى؛ لا تغيير لسياسة الالتقاط التي سمح بها المستخدم سابقًا |
| Startup error | توضيح فشل فتح قاعدة البيانات؛ لا إنشاء مكتبة بديلة فارغة تخفي مشكلة البيانات |
| Person picker | بحث واختيار واضح؛ إنشاء شخص فقط في الأماكن التي تسمح به؛ Cancel يحافظ على الحالة |
| Gallery / Files sheet | مصدران واضحان؛ إلغاء الاختيار يحافظ على الوسائط المختارة سابقًا |
| Password dialog | حقل مناسب لكلمة المرور والتحقق منها؛ الإلغاء لا يبدأ عملية؛ كلمة المرور لا تحفظ |
| Scan progress | preparing / running / waiting / paused / completed، السبب والعدد والوقت المتبقي إن توفر، مع إجراء يتبع الحالة |
| PC offline / busy / revoked | النص والإجراء يتبعان السبب؛ إعادة الفحص أو إصلاح الاتصال أو الربط مجددًا؛ لا استئناف تلقائي لتوقف اختاره المستخدم |
| خطأ تحميل | إبقاء البيانات المحفوظة؛ رسالة قابلة للفهم وإعادة المحاولة؛ تجنب تفسير قائمة فاضية على أنها نتيجة ناجحة |
| Accessibility | أزرار لمس مناسبة؛ ترتيب تركيز طبيعي؛ وضوح النص المكبر؛ رسائل أخطاء وإشارات اختيار بالنص والرمز بجانب اللون |

## ما تم تنفيذه بعد اعتماد التصميم

- ثيم عام موحد للفواتح والداكن، مع عناوين واضحة ومساحات وأزرار وحقول متناسقة. رسائل التحقق والمساعدة في الحقول تسمح بثلاثة أسطر.
- الرئيسية وStudio وخطوات Reface من المرحلة الأولى محفوظة. مسار Reface الموحد الأحدث وخياراته وIndexedStack لحفظ حالة الفيديو لم يتم استبدالها.
- التخزين يعرض إجمالي المساحة الحقيقي وأحجام الفئات مرتبة حسب الاستخدام. ملفات النماذج لا تسمى مؤقتات. تنظيف المؤقتات منفصل، وحذف النتائج ومجموعات التدريب والنماذج في قسم مستقل قابل للفتح، مع استمرار تأكيدات وخطوات الصيانة الموجودة.
