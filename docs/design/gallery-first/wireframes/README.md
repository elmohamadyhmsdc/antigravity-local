# Gallery-first wireframes

68 base surfaces + 2 result-state variants. Each screen has an editable SVG and a 390×844 PNG.

- `boards/core-path.png`: Gallery → person → model → generation → result (3 screens per row).
- `boards/atlas-01.png` to `atlas-12.png`: at most 6 screens per board.
- `boards/qa-core-corrections.png`: reviewed core corrections.
- `manifest.json`: stable IDs and asset files.
- `render-wireframes.cjs`: deterministic renderer using the installed local Sharp package.

See `../wireframe-atlas.md` for exact full content, states, actions and back behavior. These are static review artifacts, not application screenshots.
