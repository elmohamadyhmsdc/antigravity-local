## ما يظل ثابتًا في كل الشاشات

- أربع وجهات رئيسية فقط؛ الشاشات المتفرعة تفتح بـBack بدون تكرار الشريط الرئيسي.
- Gallery يبدأ بالصور المسموح الوصول إليها محليًا، حتى قبل فحصها أو ربط الكمبيوتر.
- الصورة وملف الشخص وDiscover يفتحون نفس الأدوات مع سياقهم الصحيح، بدل إنشاء نسخ متنافسة من الوظيفة.
- النتيجة ترجع لمصدرها وهوية الشخص والموديل عندما تكون الروابط معروفة؛ المصادر القديمة غير المرتبطة تُعرَّف بوضوح.
- مجموعة هوية الوجوه ليست LoRA؛ جاهزية محرك الكمبيوتر ليست موديلًا مدرَّبًا للشخص.
- تبقى كل أدوات التصحيح والتنظيم والمراجعة والتصدير والخصوصية قابلة للوصول.
- الرسومات التخطيطية توضح التوزيع والمحتوى، والملفات النصية تحتفظ بالتفاصيل التي تقع تحت التمرير وبكل الحالات المطلوبة.

## العقود التي نُفّذت

نُفّذ تصفح الصور والفولدرات المحلية قبل التحليل، وسياق الصورة والأشخاص للأدوات، ومصدر النتائج الجديدة، وحفظ روابط الموديلات والـDatasets والعلامات عند الدمج. تأكيد الحذف يوضح نوع الملفات الفعلية المتأثرة. النتائج القديمة التي تفتقد الروابط لا تُنسب لمصدر افتراضي.

تظل القيود الحالية موضحة: أدوات المجموعات والمعدات للصور، التجميع التجريبي اختياري، وعدم تحويل garment tags غير المعايرة إلى فلاتر مؤكدة.
